# 財富管理分析工具（同事版）

見客用嘅財富管理分析網頁工具，主要喺 iPad 上用。由蘇冠維（阿維）設計同管理。

網址：https://ahwai79.github.io/wealth-planning/

## 點樣用

1. 用 iPad 嘅 Safari 開上面條網址。
2. 撳 Safari 嘅「分享」→「加至主畫面」，之後好似 App 咁一撳就開。
3. 每次打開會問你：示範客戶、新客戶分析、開啟檔案，或者繼續上次。
4. 第一次用，可以喺「檔案」選單開「教學模式」，跟住見客流程指引學。去見客之前記得閂返。

## 客戶資料去咗邊

- 工具冇伺服器，唔會將任何客戶資料上載到網上。
- 輸入嘅數字只會自動儲存喺你部機嘅瀏覽器，用嚟防止 refresh 或者閂咗分頁會唔見。
- 正式紀錄要撳「檔案」→「儲存」，存一個檔案落 iCloud Drive。下次 Review 用「開啟檔案」揀返佢。
- iPad 一定要設開機密碼。
- 「清除呢部機嘅暫存」會刪走部機入面嘅暫存資料（已經存咗嘅檔案唔受影響）。

## 同 Claude 版嘅分別

- 「影建議書・AI 讀取」只喺阿維嘅 Claude 版用到。同事版要自己輸入建議書數字。
- 其他功能一樣。

## 版本同更新

- 「檔案」選單最底會顯示而家嘅版本號。
- 同事版只會喺阿維批准之後先更新。
- 有意見或者發現問題，直接話俾阿維知。

## 重要聲明

本工具只作財務規劃討論用途。所有預測均基於假設，並非保證，亦不構成投資建議；保險產品數字以保險公司正式建議書為準。工具唔代表任何保險公司，參考數據來源列喺工具入面嘅「計算方法手冊」（教學模式）。
